Connection

On GitHub Pages this is required: paste the public URL of your deployed FastAPI app (trailing slash optional). On http://127.0.0.1:8000/ you can leave this blank.

Students & tokens

Optional label is only for your own organization (e.g. desk number). After a successful fetch, tabs use each student’s Canvas display name when available.

Tokens are stored in this browser’s local storage so you do not have to paste them every visit. Avoid this on shared computers. You can clear site data anytime.
