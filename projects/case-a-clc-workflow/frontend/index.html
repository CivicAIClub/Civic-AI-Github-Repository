AutoPlanner

Personal weekly planners for every student — straight to a tidy Google Doc. Add each student’s Canvas token, preview their schedule on a tab, then create or update their Doc with one click.

  1. 1
    Connect

    Set the AutoPlanner API URL (if hosted) and your school’s Canvas address.

  2. 2
    Add students

    Each learner generates a token in Canvas → Settings → New access token.

  3. 3
    Fetch & export

    Load every schedule, review the tabs, then create or refresh each Doc.
